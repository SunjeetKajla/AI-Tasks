# Task 1 - NumPy Operations

## Overview
Basic NumPy operations demonstrating matrix manipulation, statistical calculations, and linear algebra operations.

## Features
- Random matrix generation (5x4)
- Matrix transpose operations
- Statistical calculations (column-wise mean, row-wise standard deviation)
- Matrix multiplication (dot product)

## Requirements
- numpy

## Usage
```bash
python matrix_operations.py
```

## Output
- Original 5x4 matrix
- Transposed 4x5 matrix
- Column-wise mean values
- Row-wise standard deviations
- Dot product result (5x5 matrix)
