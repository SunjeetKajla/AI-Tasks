# Task 3 - Exploratory Data Analysis (EDA)

## Overview
Comprehensive exploratory data analysis with advanced visualizations and statistical insights.

## Features
- Interactive Jupyter notebook with detailed visualizations
- Statistical analysis and data profiling
- Comprehensive EDA summary documentation

## Files
- `eda_visualisation.ipynb` - Interactive analysis notebook
- `EDA_Summary.md` - Detailed findings and insights
- `dataset/` - Contains train.csv, test.csv, and data description

## Requirements
- pandas
- matplotlib
- seaborn
- numpy
- jupyter

## Usage
```bash
jupyter notebook eda_visualisation.ipynb
```

## Analysis Includes
- Data distribution analysis
- Correlation analysis
- Missing value patterns
- Feature relationships
- Statistical summaries
