# Task 4 - Iris Species Classifier

## Overview
K-Nearest Neighbors (k-NN) classifier for predicting Iris flower species using the classic Iris dataset from scikit-learn.

## Objective
Train a k-NN classifier to predict flower species (Setosa, Versicolor, Virginica) based on sepal and petal measurements.

## Features
- Uses built-in Iris dataset from scikit-learn
- Train/test split (80/20)
- k-NN classification with accuracy reporting
- Interactive Jupyter notebook implementation

## Requirements
- scikit-learn
- matplotlib
- jupyter

## Files
- `iris_knn_classifier.ipynb` - Main implementation notebook
- `question.txt` - Task requirements

## Usage
```bash
jupyter notebook iris_knn_classifier.ipynb
```

## Dataset Details
- 150 samples (50 per class)
- 4 features: sepal length/width, petal length/width
- 3 target classes: Setosa, Versicolor, Virginica

## Model Performance
The notebook includes accuracy evaluation on the test set and detailed analysis of the k-NN classifier performance.
