# AI-ML Course Projects

## Overview
Comprehensive collection of machine learning and artificial intelligence projects covering fundamental to advanced concepts in data science, machine learning, and deep learning.

## Project Structure

### 📊 **Data Manipulation & Analysis**
- **[Task 1 - NumPy Operations](Task%201%20-%20NumPy%20Operations/)** - Matrix operations and linear algebra
- **[Task 2 - Robust Pandas Data Wrangling](Task%202%20-%20Robust%20Pandas%20Data%20Wrangling/)** - Data cleaning with Titanic dataset
- **[Task 3 - Exploratory Data Analysis (EDA)](Task%203%20-%20Exploratory%20Data%20Analysis%20(EDA)/)** - Comprehensive data visualization and analysis

### 🤖 **Machine Learning Fundamentals**
- **[Task 4 - Iris Species Classifier](Task%204%20-%20Iris%20Species%20Classifier/)** - k-NN classification
- **[Task 5 - Comparative Machine Learning Modeling](Task%205%20-%20Comparative%20Machine%20Learning%20Modeling/)** - KNN vs SVC comparison
- **[Task 6 - Data Transformation Pipeline](Task%206%20-%20Data%20Transformation%20Pipeline/)** - Preprocessing pipelines
- **[Task 7 - Feature Engineering and Selection](Task%207%20-%20Feature%20Engineering%20and%20Selection/)** - Advanced feature techniques

### 🔬 **Advanced ML Techniques**
- **[Task 8 - Cross-Validation and Regularization](Task%208%20-%20Cross-Validation%20and%20Regularization/)** - Ridge & Lasso regression
- **[Task 9 - Handling Imbalanced Data](Task%209%20-%20Handling%20Imbalanced%20Data/)** - SMOTE and class balancing

### 🧠 **Deep Learning**
- **[Task 10 - CNN for Image Classification](Task%2010%20-%20CNN%20for%20Image%20Classification/)** - CIFAR-10 classification
- **[Task 11 - LSTM for Sentiment Analysis](Task%2011%20-%20LSTM%20for%20Sentiment%20Analysis/)** - IMDB sentiment analysis

## Technologies Used
- **Data Science**: NumPy, Pandas, Matplotlib, Seaborn
- **Machine Learning**: Scikit-learn, Imbalanced-learn
- **Deep Learning**: TensorFlow, Keras
- **Development**: Python, Jupyter Notebooks

## Getting Started

### Prerequisites
```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow imbalanced-learn
```

### Running Projects
Each task contains its own README with specific instructions. Generally:

```bash
# For Python scripts
python script_name.py

# For Jupyter notebooks
jupyter notebook notebook_name.ipynb
```

## Learning Path
1. **Start with Tasks 1-3** for data manipulation fundamentals
2. **Progress to Tasks 4-5** for basic ML concepts
3. **Advance to Tasks 6-9** for sophisticated ML techniques
4. **Complete with Tasks 10-11** for deep learning applications
